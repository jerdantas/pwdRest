The client stores the userid, password in the home/.local/pwd-client/.env file. If this file does not exist,
the client opens a dialog for login or signup request.
The login and signup dialogs are implemented in the client in files LoginDialog.cpp, LoginDialog.h, and LoginDialog.ui.
The login dialog must have a OwnerId field and a Password field, and a Login, Signup, and Cancel button.
The Signup button must be enabled only if the OwnerId field is empty.
The Login button must be enabled only if the OwnerId field is not empty.
The Cancel button must be enabled always.
 he Login button must call the Login() which is implemented in PasswordClient.cpp.
The signup dialog must have a OwnerName field, a UserName field and a Password field.
The Signup button must call the Signup() method which is like the ensureCredentials() method in client_main.cpp.
